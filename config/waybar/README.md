# Waybar

Static Waybar configuration lives here.

The goal is a lightweight island-style top bar with:

- workspaces;
- active window;
- audio;
- battery;
- network with `nmtui` on click;
- current keyboard layout;
- clipboard;
- power button;
- clock/calendar trigger.

Files:

- `config.jsonc`: bar layout;
- `modules.jsonc`: module behavior and click actions;
- `style.css`: visual theme using generated colors.
